# Aditya -- Fullstack Dev (portfolio)

React + TypeScript + Tailwind CSS + Framer Motion + Lucide React, built with Vite.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Structure
- `src/sections/` Hero, Marquee, About, Services, Projects
- `src/components/` FadeIn, Magnet, AnimatedText, ContactButton, LiveProjectButton
- `src/data.ts` image URLs, projects, services copy
